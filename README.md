# Network Design and Simulation using Cisco Packet Tracer

A network design and simulation project saved as a Cisco Packet Tracer `.pkt` file.

## Project file

- `Network Design and Simulation using Cisco Packet Tracer.pkt`

## Open the project

1. Download or clone this repository.
2. Launch Cisco Packet Tracer.
3. Choose **File → Open** and select the `.pkt` file.
4. Explore the saved network topology and device configurations.

Cisco Packet Tracer is required to open the project. GitHub does not display an interactive preview of `.pkt` files; download the file to view it in Packet Tracer.
